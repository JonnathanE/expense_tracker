# Image Specifications in frontend/public

## og-image.png

| Property       | Value            |
| -------------- | ---------------- |
| Format         | PNG              |
| Dimensions     | 1200 × 630 px    |
| Aspect ratio   | 1.91:1           |
| Max file size  | ~300 KB          |
| Color space    | sRGB             |

Used for Open Graph social sharing (Facebook, LinkedIn, WhatsApp, Discord, etc.).

## apple-touch-icon.png

| Property       | Value            |
| -------------- | ---------------- |
| Format         | PNG              |
| Dimensions     | 180 × 180 px     |
| Max file size  | ~100 KB          |
| Color space    | sRGB             |

Used when iOS users add the app to their Home Screen.
